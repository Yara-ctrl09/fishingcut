# 피싱 사이트 구분 도우미

이 프로젝트는 URL을 입력해 피싱 사이트 의심 여부를 간단히 확인할 수 있는 웹페이지입니다.

## 기능
- URL 입력 후 분석 실행
- HTTPS, IP 주소, 의심 키워드, 유사 도메인 패턴 확인
- 결과를 간단하게 표시

## 실행 방법
1. 프로젝트 폴더로 이동합니다.
2. 브라우저에서 `index.html` 파일을 열거나,
3. 로컬 서버를 실행해 확인할 수 있습니다.

### 로컬 서버 실행 예시
```bash
python -m http.server 8000
```

그다음 브라우저에서 다음 주소로 접속합니다.

```text
http://127.0.0.1:8000/
```

## 참고
- 이 도구는 교육용/실험용으로 만든 간단한 판별 도구입니다.
- 실제 사이트 안전 여부를 완전히 보장하지는 않습니다.
